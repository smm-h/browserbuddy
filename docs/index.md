# BrowserBuddy

BrowserBuddy turns your real browser into a space you share with an AI assistant: an MCP stdio server plus a cross-browser WebExtension that let an agent act in, and observe, the same window you are already using. The project README covers setup and the tool catalog; the two documents below are the reference material.

- [Architecture](ARCHITECTURE.md) -- components, data flow, and the reasoning behind the design.
- [Protocol](PROTOCOL.md) -- the normative extension/hub wire contract.
